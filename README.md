# A Small Counter Application
## Built with React - typescript - vite

### Clone the project and cd Counter
### Then do npm install
### npm run dev

#### There's four components that act as counters, but you can also add more counters by clicking the "Add Counter" button.
#### You can also remove the counters but it wont remove the value from the current value which is displayed at the top.
#### It will reset when the current amount hits 10, which will then reset the buttons and the current amount which will be added to the collector.
